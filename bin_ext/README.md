# Touhou Danmakufu ph3sx FileArchiver

FileArchiver creates encrypted `.dat` archives for use with the ph3sx engine.
These archives are not compatible with vanilla Danmakufu ph3.

Use the FileArchiver version distributed with the same ph3sx release as your
engine. Keep backups of source files and archives; compatibility with other
engine versions is not guaranteed.
