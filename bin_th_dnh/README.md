# Touhou Danmakufu ph3sx

## Installation

Extract the complete distribution archive to a folder of your choice. Keep the
`resource/` folder alongside the engine executable.

## Supported platform

This release targets 32-bit Windows and DirectX 9. A native macOS build is not
available. Running the Windows build through Wine is not officially supported;
compatibility depends on the Wine version and installed DirectX components.

## Executables

- `th_dnh_ph3sx.exe` — standard engine.
- `th_dnh_ph3sx_legacy.exe` — alternative build for systems that have problems
  with the standard executable. If the standard build fails to start or renders
  incorrectly, try the legacy build.

## Default controls

| Input | Action |
| --- | --- |
| Arrow keys | Move |
| Z | Shoot / select |
| X | Bomb / cancel |
| Left Shift | Focused movement |
| Left Ctrl | Fast mode |
| R | Return to script select, when allowed by the script |
| Backspace | Restart the script, when allowed by the script |

Scripts may override these defaults. Controller mappings can be changed in the
configuration utility.

## Compatibility

ph3sx replay files, saved common data, and `.dat` archives are not
interchangeable with vanilla Danmakufu ph3.

## Uninstallation

Delete the extracted distribution folder. Back up any scripts, configuration,
replays, or saved data you want to keep.
