# ph3sx documentation

This section collects architecture and scripting-language documentation for
Touhou Danmakufu ph3sx. The documents describe ph3sx-specific behavior and
should not be assumed to apply to vanilla Danmakufu ph3.

## Guides and references

| Document | Contents |
| --- | --- |
| [Engine architecture and platform migration](./architecture.md) | Current engine structure, SDL3 integration, build scope, and cross-platform roadmap. |
| [Scripting language features](./scripting-language.md) | Language syntax, types, operators, control flow, and other ph3sx additions. |
| [Script API reference](./script-api.md) | Constants and built-in functions available to scripts. |
| [Script style guide](./style-guide.md) | Naming, formatting, and organization conventions for scripts. |

## Version notes

These references are based on the documentation distributed with this source
tree. They may describe features that differ between ph3sx versions. Verify
behavior against the engine version used by your project.
